# Публикация SayWord в RuStore

## Что в этой папке

| Файл | Зачем |
|---|---|
| `listing.md` | Тексты для карточки приложения: название, описания, категория, возраст |
| `icon-512.png` | Иконка 512×512 для магазина |
| `../../PRIVACY.md` | Политика конфиденциальности — ссылка на неё указывается в карточке |

Ключ подписи в репозитории **не хранится**: он лежит в секретах GitHub.

## Шаг 1. Секреты GitHub (один раз)

Settings → Secrets and variables → Actions → **New repository secret**, четыре штуки:

| Имя | Значение |
|---|---|
| `KEYSTORE_BASE64` | ключ подписи, закодированный в base64 |
| `KEYSTORE_PASSWORD` | пароль хранилища ключа |
| `KEY_ALIAS` | `sayword` |
| `KEY_PASSWORD` | пароль ключа (совпадает с паролем хранилища) |

Пока секретов нет, CI проверяет release-сборку одноразовым ключом, но файл
для магазина не выкладывает.

## Шаг 2. Собрать версию для магазина

Actions → **Build APK** → **Run workflow** → ветка `main` → Run.
Через 5–7 минут в артефактах запуска появится **`sayword-release`**:
внутри `app-release.apk` — его и загружать в RuStore.

Каждый запуск CI получает новый номер, поэтому номер версии растёт сам:
это требование магазина к каждому обновлению.

## Шаг 3. Проверить на телефоне

Установите `app-release.apk`. У версии для магазина другое имя пакета
(`ru.sayword.english`), поэтому рядом с тестовой появится вторая иконка —
тестовую лучше удалить. Слова из тестовой версии не переносятся.

## Шаг 4. Скриншоты

Снимите на телефоне 4–6 экранов: заставка, список тем, слово с результатом,
итог с салютом, «Мои слова», добавление слова. Перед съёмкой уберите лишние
значки из строки состояния, если получится.

## Шаг 5. Карточка в консоли RuStore

console.rustore.ru → новое приложение → загрузить `app-release.apk` →
заполнить поля текстами из `listing.md` → иконка `icon-512.png` → скриншоты →
категория «Образование» → возраст 0+ → ссылка на политику → контакты →
отправить на модерацию.

## Обновления

Любое изменение в `main` собирает новую `sayword-release`. Загружайте её в
консоли как новую версию того же приложения. Подписывать обновления можно
**только тем же ключом**, поэтому ключ нельзя терять.
