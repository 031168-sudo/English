# English Pronunciation Trainer

Android-приложение для тренировки произношения английских слов. Рассчитано
на русскоязычных пользователей: часто встречающиеся звуки (th, w/v) и слова
с непривычным ударением включены в словарь намеренно.

## Как это работает

1. На экране показывается картинка (эмодзи), слово, транскрипция и перевод.
2. По кнопке «Слушать» слово произносится дважды: сначала медленно, затем
   в обычном темпе (Android TextToSpeech, английский голос).
3. По кнопке «Повторить слово» приложение слушает через микрофон
   (`RecognizerIntent`) и распознаёт сказанное.
4. Распознанный текст сравнивается с целевым словом через нормализованное
   расстояние Левенштейна — результат показывается в процентах с обратной
   связью (отлично / нужно потренироваться / попробуй ещё раз).
5. Кнопка «Следующее слово» переходит дальше по списку; внизу экрана виден
   средний результат за сессию.

## Ограничения подхода к оценке

Оценка строится на сравнении текста, распознанного системным
speech-to-text, с ожидаемым словом — это доступный на устройстве способ
оценить произношение без внешних сервисов и обучения моделей. Он не
анализирует фонемы напрямую, поэтому если распознаватель речи угадывает
слово несмотря на акцент, процент может быть выше, чем реальное качество
произношения. Для более точной фонетической оценки потребуется отдельный
ML-движок (например, on-device forced alignment), это можно добавить позже.

## Сборка

Проект собирается через Gradle (Kotlin + Jetpack Compose), обёртка gradle
не закоммичена — CI и Android Studio используют системный/скачиваемый
Gradle 8.10.

```bash
gradle assembleDebug
```

APK также собирается автоматически в GitHub Actions при пуше в `main`
(см. `.github/workflows/build-apk.yml`) и доступен во вкладке Actions как
артефакт `english-pronunciation-trainer-debug`.

## Требуемые разрешения

- `RECORD_AUDIO` — для распознавания произнесённого слова.
- `INTERNET` — системный распознаватель речи на многих устройствах
  использует облачное распознавание.

Для работы распознавания речи на устройстве должно быть приложение
Google (или другой сервис), поддерживающее `RecognizerIntent`.
